# Excursia Connect

## 🌐 Live Website

**Website:** https://www.excursiaconnect.com

Excursia Connect is a travel and events platform designed to connect travelers, businesses, and organizations with exceptional travel experiences, business travel solutions, and MICE services.

---

## 📌 Project Information

This project is the official web application for **Excursia Connect**.

The platform provides users with access to travel experiences and professional travel solutions, including:

- Leisure and holiday travel
- Tours and excursions
- Business travel
- Meetings, Incentives, Conferences and Exhibitions (MICE)
- Corporate travel solutions
- Event and travel management services

The website is designed to provide a modern, responsive, and user-friendly experience across desktop, tablet, and mobile devices.

---

## 🛠️ Technologies Used

This project is built using modern web development technologies:

- **React** – Frontend JavaScript framework
- **TypeScript** – Type-safe development
- **Vite** – Fast development and production build tool
- **Tailwind CSS** – Utility-first CSS framework
- **shadcn/ui** – Reusable and accessible UI components
